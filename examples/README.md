# Synthetic example provenance

These images were generated by this repository's `evaluate.py` on 2026-11-07. They contain invented generic exercise text, drawn triangles and blank tables. No real examination paper, student answer, name, school, identifier or private customer material is included.

The Chinese text was rendered with Noto Sans SC. The font binary is not redistributed. Noto CJK source: https://github.com/notofonts/noto-cjk . Font license: SIL Open Font License 1.1; a copy is supplied in `third_party/SIL-OFL-1.1.txt`. That font license does not apply to the rendered example image as a whole.

- `input/`: the original generated JPEGs.
- `synthetic/`: normalized input JPEGs, actual local inference JSON and overlays.

To rerun inference on the included images:

```sh
python evaluate.py --images examples/input --output output/demo
```

To generate fresh Chinese pages, obtain an appropriately licensed font, create a new empty input directory, and run:

```sh
python evaluate.py --images path/to/empty-input --output output/fresh --synthetic-font path/to/NotoSansSC-Regular.ttf
```

Do not mistake the synthetic four-question result for a general accuracy evaluation. The continuation example deliberately has no reliable main question numbers and should require manual selection.
